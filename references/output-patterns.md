## Dashboard-ops presentation

- Prefer one full-width dashboard composition.
- If showing dark + light grammars, **stack vertically** with generous height each (~min 520px), or use a wide 2-col only when viewport ≥1200px and each column ≥540px.
- KPI numbers large; charts ≥160px tall; filters readable (≥12px).

## Image generation constraints (website)

```text
designed for a full-screen website section, not an ultra-wide banner;
16:10 or 4:3-friendly composition; vertical breathing room;
safe space for headline and CTA; no critical crop at edges
```

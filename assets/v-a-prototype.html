2. 已拍板规则（落地时写入 skill）

Floor / Ceiling

抬高最低标准，不锁死上限

规范是地板。AI 可叠加、可更强、可自选；默认走地板，冲突时优先用户意图并说明。

User layout

全局排版优先 + 披露

memory / CLAUDE.md / 习惯架 → 结构跟用户，只套皮肤。回复需写明：「已按你的全局排版套 [style] 皮肤」。

Skin

皮肤范围

Color · Type · Radius · Border · Shadow ·（可选）icon stroke。不含强制 Hero / 100svh。

Motion

有 su-motion 就配对

做 website 时若环境有 su-motion-top12，默认两 skill 一起用；没有也不失败。

模式：Browse / Choose / Recommend / Auto / Apply。 探索才上课；建页/优化默认 Auto。Apply 出 Contract（深|浅）再实现、再 Evidence。
